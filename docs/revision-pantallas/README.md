# Revisión final de pantallas

Abre los archivos HTML en el navegador y usa las flechas o el selector inferior para cambiar de vista. Si estás en GitHub, descarga los archivos antes de abrirlos.

| Visor | Vistas |
| --- | ---: |

Las pantallas usan datos de ejemplo. El selector de planes y los formularios simulan sus interacciones sin enviar datos ni iniciar pagos.

El visor de Torneos incluye las ilustraciones dentro del HTML. Las vistas de campeón y victoria generan una imagen vertical para compartir.
